# SurfaceForge VR 模擬版開發文件

日期：2026-11-06

狀態：討論整理與開發規劃，尚未代表已實作或驗收。

## 1. 目標與範圍

在沒有 VR 頭盔與控制器的情況下，以鍵盤滑鼠模擬角色、左右控制器、控制器旁的道具 UI，以及射線放置與選取流程。保留現有桌面模式，並讓之後的實際控制器輸入能沿用放置規則。

本文件整理專案的互動設計。模擬版不代表完成 VR 裝置整合；頭部追蹤、雙眼顯示、硬體按鍵與裝置相容性仍需實機驗證。

## 2. 已確認的設計方向

- 以一個膠囊代表角色身體，兩個小球代表左右控制器。
- 按 Tab，在左側小球旁展開／收合道具 UI。
- 以控制器按鍵操作為設計基礎，不實作翻掌或其他手勢辨識。
- 右側小球發出射線，負責操作 UI、拖出道具、放置及選取。
- 第一版左右小球跟隨角色，維持固定相對位置；不要求用鍵鼠獨立操作雙手的六自由度姿態。

以下操作映射、元件名稱與細節為建議實作基線，可於試玩後調整。

## 3. 角色與攝影機

建議階層：

```text
SimulationPlayer（角色根節點／移動與水平轉向）
├─ Body（膠囊外觀）
├─ ViewPivot（觀看俯仰）
│  ├─ Camera（第一人稱透視攝影機）
│  ├─ LeftController（左小球）
│  │  └─ MenuAnchor
│  │     └─ PropMenu（World Space Canvas）
│  └─ RightController（右小球）
│     └─ RayOrigin
```

小球置於攝影機前方偏左、偏右，使操作時可辨識控制器位置。身體模型應避免遮擋第一人稱畫面。手部距離、面板尺寸、視角上下限與移動速度集中於 Inspector 調整。

WASD 以水平觀看方向移動；第一版不包含跳躍、攀爬或獨立手部移動。角色是否貼地行走、採用何種碰撞與可移動範圍，於角色階段確認，避免直接沿用任意飛行行為。

模擬模式停用原本的自動取景攝影機邏輯，避免 `TerrainOverviewCamera` 每幀覆寫視窗或取景設定。

## 4. 建議鍵鼠映射

| 輸入 | 行為 |
| --- | --- |
| WASD | 移動角色 |
| 按住右鍵並移動滑鼠 | 轉動角色視角；期間暫停滑鼠瞄準更新 |
| 一般移動滑鼠 | 調整右控制器射線方向 |
| Tab | 展開／收合左控制器旁的道具面板 |
| 左鍵按住道具項目並拖出 | 模擬扳機抓取，開始道具預覽 |
| 放開左鍵 | 有效落點放置；無效落點取消 |
| 左鍵點已放置道具 | 選取並顯示刪除選單 |
| Esc | 優先取消拖曳；沒有拖曳時關閉道具面板 |

右鍵觀看時鎖定／隱藏游標，結束後恢復。拖曳期間先禁止進入右鍵觀看，避免同一次滑鼠操作同時改變視角與放置方向。失焦或模式切換時必須恢復游標狀態。

## 5. 左控制器道具面板

- 使用 World Space Canvas，初始收合。
- 面板位於左球上方略偏前，正面朝向觀看者；第一版跟隨左控制器錨點。
- 沿用既有道具定義、圖示與 prefab；採適合射線點選的項目尺寸。
- 面板內容可捲動；滑鼠滾輪僅在射線命中清單區域時捲動。
- Tab 關閉面板時，若正在拖曳，先取消並清除預覽與指引線。
- 開始拖出道具後，保留來源資料與手勢擁有權；可淡化面板並停用其他項目的新操作，但面板仍阻擋向後穿透的場景操作。
- 保留既有桌面右側清單；依模式啟用對應呈現，不讓兩套 UI 同時接收同一輸入。

不直接沿用桌面清單「向左拖曳複製、垂直拖曳捲動」的手勢分類。模擬模式建議以射線在面板上的移動距離判定拖曳門檻，再於拖出項目後進入放置；門檻數值實測調整。

## 6. 右控制器射線與輸入優先順序

瞄準流程：

1. 由攝影機與滑鼠螢幕座標取得瞄準參考點；沒有命中時使用有限距離的參考點。
2. 從右球 `RayOrigin` 朝參考點建立實際互動射線。
3. UI、地形與道具操作都以這條控制器射線判定，攝影機參考命中不直接當成操作結果。

射線顯示起點、終點與命中標記。控制器與眼睛位置不同時，允許實際命中與滑鼠參考點有差異，畫面回饋需呈現實際結果。

輸入路由依序處理：

1. 已取得手勢擁有權的拖曳流程，持續處理直到放開或取消。
2. 沒有拖曳時，先判定可見且未被遮擋的 UI；UI 吃掉操作後，不觸發背後的地形或道具。
3. 其餘情況才接受場景選取。

UI 與場景命中需依距離及遮擋規則比較，不能讓面板穿過前景物件接受點擊。放置查詢則維持既有專用 Surface 規則，預覽與已放置道具不遮擋地形落點查詢。

## 7. 道具放置與選取流程

### 放置

1. Tab 開啟左手面板。
2. 右手射線指向道具，按住左鍵。
3. 超過拖曳門檻並拖出項目後，建立唯一一個對應預覽。
4. 射線指向指定 TerrainCollider，依命中位置、法線與底部錨點更新姿態。
5. 顯示有效／無效預覽、射線與落點指引；在 UI 上隱藏放置預覽，不保留可提交的舊落點。
6. 放開時重新查詢 UI 與地形；有效就建立一個正式道具，否則取消。
7. 清理預覽、指引與手勢狀態，清單來源保留供重複操作。

取消條件包含 Esc、Tab 關閉面板、失焦、離開有效視窗、控制器停用與模式切換。中斷後回到視窗不得意外放置。放置結束的同一次放開不得額外觸發選取。

### 選取與刪除

沒有拖曳且射線不被 UI 接收時，點擊已放置道具可選取；點擊另一道具切換，點擊地形或空白清除。來源面板的新拖曳也清除選取。

模擬模式建議使用物件旁的世界空間刪除選單，朝向觀看者並可由右手射線操作；桌面模式維持現有螢幕空間選單。新選單需處理遮擋、距離與可讀性，避免直接套用目前的螢幕邊界限制。刪除後清除目標與選單參照。

## 8. 程式責任與現有系統整合

沿用 Unity、URP、Input System、UGUI 與既有道具資料，不以模擬需求為由升級套件。純鍵鼠模擬可先使用自訂輸入與射線轉接，不預設必須安裝 XR 套件；正式接設備時再選定套件與硬體。

| 責任 | 建議處理方式 |
| --- | --- |
| 角色移動與觀看 | 獨立模擬角色元件，避免放入放置控制器 |
| 控制器射線 | 輸出世界射線、命中與按下／持續／放開意圖 |
| 左手面板 | 管理錨點、開關與道具項目呈現 |
| UI 與場景輸入路由 | 統一判定命中、遮擋、手勢擁有權與事件消耗 |
| 放置流程 | 共用開始、更新、確認、取消及預覽生命週期 |
| 地形查詢 | 接受世界射線；桌面螢幕座標透過攝影機轉成射線後共用 |
| 選取與選單 | 共用選取目標與刪除規則，各模式使用適合的呈現 |
| 模式切換 | 取消互動、清除選取，再切換攝影機、輸入與 UI |

現有 `PlacementController` 直接依賴滑鼠、螢幕座標及 `PropItemDragHandler`，不能只把 Canvas 移到左球就視為完成。需把來源手勢與取消條件移到輸入轉接層，讓放置核心接受射線與操作意圖；保留桌面操作的相容入口及回歸測試。

維持明確元件與 Inspector 參照，不導入大型框架。UI 事件系統需統一管理，避免桌面與模擬輸入同時送出事件。

模式初期可由啟動設定選擇 Desktop／VR Simulation；執行中切換屬後續項目，需另驗證切換期間的狀態清理。

## 9. 開發順序

| 階段 | 內容 | 完成條件 |
| --- | --- | --- |
| S1 | 膠囊、雙球、第一人稱攝影機與移動 | 能觀看及移動，身體不遮擋操作 |
| S2 | 左球面板與 Tab 開關 | 初始收合，開關穩定，四種道具可見 |
| S3 | 右球射線與 UI 路由 | 可指向、點選、捲動，無 UI 穿透 |
| S4 | 射線放置與共用核心 | 可重複拖出、預覽、放置與取消，桌面功能無退化 |
| S5 | 射線選取與刪除 | 可切換目標，刪除只影響該實例 |
| S6 | 邊界驗證與桌面建置 | 中斷、比例變化與獨立執行檔驗收完成 |

桌面必要功能與指引線的既有工作仍需完成；模擬版不取代原本交付與驗收。

## 10. 驗收清單

- [ ] 膠囊與左右小球關係正確，攝影機與移動方向一致。
- [ ] Tab 在左球旁開關面板，不產生重複 UI。
- [ ] 射線從右球發出，UI 與場景操作使用相同射線。
- [ ] 面板可點選與捲動；UI 遮擋、輸入消耗與拖曳擁有權正確。
- [ ] 四種道具皆可重複拖出，來源項目保留，每次最多一個預覽。
- [ ] 高處、低處、斜坡與邊界內可放置，姿態與預覽一致。
- [ ] UI 上、地形外及無命中處放開，不建立物件且不沿用舊落點。
- [ ] Esc、Tab、失焦、離開視窗及停用均清理拖曳；回到視窗不誤放置。
- [ ] 可選取、切換、清除及刪除；放置放開不額外選取。
- [ ] 右鍵觀看與瞄準沒有輸入衝突，失焦後游標恢復正常。
- [ ] 桌面模式的原有放置、取消、選取與刪除通過回歸驗證。
- [ ] 16:9、4:3、寬螢幕及執行中縮放後，射線與 UI 仍對應正確。
- [ ] 在 Editor 外的 Windows 建置完成主要流程，記錄版本、結果與限制。

對狀態轉換、取消與單次建立等高風險邏輯增加必要測試；UI 尺寸與觀看舒適度以人工操作調整。驗收紀錄明確區分鍵鼠模擬通過與尚未進行的 VR 實機驗證。

## 11. 待實作時確認的參數

- 角色尺寸、地形尺度、貼地與碰撞方式、移動邊界。
- 左右球偏移、面板尺寸與距離、射線長度、拖曳門檻。
- 觀看靈敏度、俯仰限制與游標恢復位置。
- 世界空間刪除選單的距離、尺寸與遮擋處理。
- 模擬模式採獨立場景或共用主場景的啟動設定。

以上不影響已確認的核心方向：膠囊加兩球、Tab 左手面板、右手射線操作，以及不實作手勢翻轉。
