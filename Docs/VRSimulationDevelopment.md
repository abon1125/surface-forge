# SurfaceForge VR 模擬版開發文件

日期：2026-11-06

狀態：2026-11-06 已完成 S0 與 S1 角色／移動實作及 Editor 基本驗證；S1 已獲使用者 Editor Play Mode 人工確認（陡坡人工測試因場景無陡坡而略過），S2 左球面板已實作，技術驗證與人工驗收狀態見 [S2 驗證紀錄](S2Validation.md)；S3 射線與 UI 路由已實作，技術結果與人工確認限制見 [S3 驗證紀錄](S3Validation.md)；S4 已實作，實際測試及待人工確認範圍見 [S4 驗證紀錄](S4Validation.md)；S5 與 I1–I2 仍為後續規劃。詳見 [S0 驗證紀錄](S0Validation.md)及 [S1 驗證紀錄](S1Validation.md)。

## 1. 目標與範圍

在沒有 VR 頭盔與控制器的情況下，以鍵盤滑鼠模擬角色、左右控制器、控制器旁的道具 UI，以及射線放置與選取流程。保留現有桌面模式，並讓之後的實際控制器輸入能沿用放置規則。

採用獨立場景 `Assets/SurfaceForge/Scenes/VRSimulation.unity`，不將模擬角色及 UI 加入桌面 `Main.unity`。開發期間直接開啟各場景測試；桌面與 VR 模擬皆完成後，再新增啟動場景選單，整合為單一 Windows App。原桌面 M5 指引線與落點標記由本場景承接，原 M6 完整邊界修正、整合測試與正式建置移至最後的選單整合階段。

本文件整理專案的互動設計。模擬版不代表完成 VR 裝置整合；頭部追蹤、雙眼顯示、硬體按鍵與裝置相容性仍需實機驗證。

## 2. 已確認的設計方向

- 以一個膠囊代表角色身體，兩個小球代表左右控制器。
- 按 Tab，在左側小球旁展開／收合道具 UI。
- 以控制器按鍵操作為設計基礎，不實作翻掌或其他手勢辨識。
- 右側小球發出射線，負責操作 UI、拖出道具、放置及選取。
- 第一版左右小球跟隨角色，維持固定相對位置；不要求用鍵鼠獨立操作雙手的六自由度姿態。

以下操作映射、元件名稱與細節為建議實作基線，可於試玩後調整。

## 3. 角色與攝影機

### 獨立場景與資產邊界

- S0 已配置獨立 Terrain、燈光、暫時檢視攝影機、AudioListener 與單一 EventSystem，可在沒有 Main 或選單場景的情況下直接進入 Play Mode。S1 已以角色第一人稱攝影機取代暫時攝影機，加入膠囊及雙球；放置、選取及世界空間 UI 仍於 S2–S5 逐階段加入。
- 複製現有 TerrainData 至 `Assets/SurfaceForge/Terrain/VRSimulationTerrain.asset` 作為起點，新場景 Terrain 與 TerrainCollider 皆參照此副本；調整 VR 地形高度與尺寸不回寫桌面 TerrainData。Terrain 保持 Surface layer。
- 共用既有 PropDefinition、道具 prefab、圖示及適用材質。TerrainLayer 與材質若需 VR 專用調整，先另存副本，避免共享資產修改影響桌面。
- 場景參照使用 Inspector 明確配置，不從 Main 尋找物件，不使用跨場景單例或 DontDestroyOnLoad 保存操作狀態。
- 不加入桌面右側清單、螢幕空間刪除選單及 TerrainOverviewCamera；VR 使用自己的全視窗攝影機與世界空間 UI。

### 角色階層

建議階層：

```text
SimulationPlayer（角色根節點／移動與水平轉向）
├─ Body（膠囊外觀）
├─ ViewPivot（觀看俯仰）
│  ├─ Camera（第一人稱透視攝影機）
│  ├─ LeftController（左小球）
│  │  └─ MenuAnchor
│  │     └─ PropMenu（World Space Canvas）
│  └─ RightController（右小球）
│     └─ RayOrigin
```

小球置於攝影機前方偏左、偏右，使操作時可辨識控制器位置。身體模型應避免遮擋第一人稱畫面。手部距離、面板尺寸、視角上下限與移動速度集中於 Inspector 調整。

WASD 以水平觀看方向移動；第一版不包含跳躍、攀爬或獨立手部移動。S1 採用使用者確認的貼地、CharacterController 碰撞與有限地形邊界方案，詳見本節決策。

新場景不掛載原本的自動取景攝影機邏輯，避免 `TerrainOverviewCamera` 每幀覆寫視窗或取景設定；Main 的攝影機設定保留。

S0 暫時攝影機僅供固定視角檢視地形，沒有觀看或移動輸入，不代表 S1 角色參數已選定。TerrainData 尺寸沿用桌面起點 80 × 18 × 64 公尺，高度圖解析度 257；共享 TerrainLayer、貼圖及材質保持原樣。Main 啟動設定與建置清單維持原狀。

### S1 角色行為決策（2026-11-06 使用者確認）

- 貼地行走、重力，不跳躍；上下緩坡，坡度超過 45° 時不得向上爬。
- 使用 CharacterController 膠囊碰撞；初始身高 1.8 m、半徑 0.3 m、階差 0.25 m。身體外觀不另加碰撞器，左右球僅為視覺標記。
- 依明確指定的 VR Terrain 範圍限制 XZ，邊界內縮膠囊半徑加安全距離；到邊緣停止，不允許走出有限地形墜落。初始位置落於有效地面；異常超界時回到最近有效地面。
- 角色根節點負責水平轉向與移動，ViewPivot 負責俯仰；雙球固定於 ViewPivot 下。尺寸、偏移、速度、靈敏度及俯仰範圍集中於角色 Inspector。

S1 初始參數：速度 4 m/s、重力 20 m/s²、skin width 0.03 m、邊界安全間距 0.05 m（連同半徑實際內縮 0.38 m）；眼高 1.65 m、球直徑 0.12 m，左右偏移 (±0.28, -0.25, 0.55) m；觀看靈敏度 0.12°/pixel，俯仰 -75°～75°。膠囊預設 ShadowsOnly，Inspector 可開啟外觀；攝影機 FOV 70°、near clip 0.05 m。右鍵放開／中斷後恢復游標可見且不鎖定；回焦或重啟元件仍按住右鍵時，需先放開再按下。以上是可調整初值，觀看舒適度由使用者決定先維持現狀，日後有需求再調整。

## 4. 建議鍵鼠映射

| 輸入 | 行為 |
| --- | --- |
| WASD | 移動角色 |
| 按住右鍵並移動滑鼠 | 轉動角色視角；期間暫停滑鼠瞄準更新 |
| 一般移動滑鼠 | 調整右控制器射線方向 |
| Tab | 展開／收合左控制器旁的道具面板 |
| 左鍵按住道具項目並拖出 | 模擬扳機抓取，開始道具預覽 |
| 放開左鍵 | 有效落點放置；無效落點取消 |
| 左鍵點已放置道具 | 選取並顯示刪除選單 |
| Esc | 優先取消拖曳；沒有拖曳時關閉道具面板 |

右鍵觀看時鎖定／隱藏游標，結束後恢復。拖曳期間先禁止進入右鍵觀看，避免同一次滑鼠操作同時改變視角與放置方向。失焦、元件停用或場景卸載時必須恢復游標狀態。

## 5. 左控制器道具面板

- 使用 World Space Canvas，初始收合。
- 面板位於左球上方略偏前，正面朝向觀看者；第一版跟隨左控制器錨點。
- 沿用既有道具定義、圖示與 prefab；採適合射線點選的項目尺寸。
- 面板內容可捲動；滑鼠滾輪僅在射線命中清單區域時捲動。
- Tab 關閉面板時，若正在拖曳，先取消並清除預覽與指引線。
- 開始拖出道具後，保留來源資料與手勢擁有權；可淡化面板並停用其他項目的新操作，但面板仍阻擋向後穿透的場景操作。
- 桌面右側清單僅保留在 Main，新場景只配置左控制器面板，不讓兩套 UI 同時接收同一輸入。

不直接沿用桌面清單「向左拖曳複製、垂直拖曳捲動」的手勢分類。模擬模式建議以射線在面板上的移動距離判定拖曳門檻，再於拖出項目後進入放置；門檻數值實測調整。

### S2 實作邊界（2026-11-06）

MenuAnchor 上的 SimulationPropMenu 常駐處理 Tab／Esc 的 wasPressedThisFrame 按下事件（包含同影格按放）與收合，停用／重啟與場景重新載入回到收合；失焦或暫停後須先放開 Tab。面板跟隨左球並朝向明確指定的 Camera，不接管游標或右鍵觀看。Inspector 提供公尺偏移、380 × 380 畫布尺寸、0.001 m/pixel 與朝向微調；初值偏移 (0, 0.29, 0.15) m，抵銷 S1 球的視覺縮放，不調整 S1 參數。

SimulationPropCatalog 以四個場景項目重用 PropCatalogItemView 的純顯示 Bind，不使用桌面 PropCatalogView 或 PropItemDragHandler，不動共用道具資料。四項同時可見，本階段不需要 ScrollRect；Canvas 無 GraphicRaycaster，CanvasGroup 不接受互動或射線，所有 Graphic.raycastTarget=false，既有 InputSystemUIInputModule 無法透過普通滑鼠操作清單。捲動、射線、拖曳、取消及放置仍留待 S3–S5，不建立空殼系統。

### S2 動畫補充（2026-11-06）

使用者導入 DOTween 免費版 1.3.045 後，S2 改用從左球展開的位移、縮放及淡入動畫。單一 progress Tween 由 0 到 1，MenuAnchor 仍逐幀跟隨並朝向 Camera；Canvas 在左球位置與最終錨點間插值，縮放由 15% 到原尺寸、CanvasGroup.alpha 由 0 到 1，不改 S1 球偏移或面板最終構圖。預設開啟 0.25 秒 OutCubic、收回 0.18 秒 InCubic；時間、比例及 Ease 可於 Inspector 調整。使用 unscaled time，動畫不受 Time.timeScale 暫停影響。

IsExpanded 表示目標開關狀態，收回期間 Canvas 仍有效但依舊不接受互動；完成才停用。Tab／Esc 從當前進度切換，僅保留一個自有 Tween，不重建 UI；剩餘時長依進度距離縮短。失焦或應用程式暫停時終止動畫並對齊當前目標，仍需放開 Tab 再按；停用、重啟或卸載回到收合並清理。Tween 綁定常駐 MenuAnchor，清理只作用於自身；DOTween 的套件持久 driver 由套件管理，專案不另建跨場景單例或呼叫 KillAll。使用者已於 2026-11-06 回報含動畫的 S2 測試 OK，未另列逐項案例；動畫及確認範圍限制見 S2Validation 的補記。

## 6. 右控制器射線與輸入優先順序

瞄準流程：

1. 由攝影機與滑鼠螢幕座標取得瞄準參考點；沒有命中時使用有限距離的參考點。
2. 從右球 `RayOrigin` 朝參考點建立實際互動射線。
3. UI、地形與道具操作都以這條控制器射線判定，攝影機參考命中不直接當成操作結果。

射線顯示起點、終點與命中標記。控制器與眼睛位置不同時，允許實際命中與滑鼠參考點有差異，畫面回饋需呈現實際結果。

控制器操作射線用於瞄準、UI 與場景互動；放置指引線則在拖曳時連接預覽與實際地形落點，並顯示落點標記，承接原桌面 M5。兩者需能視覺區分：放置指引在 UI 上或無合法地形命中時隱藏，不留下舊落點；成功、取消或中斷後清除。控制器操作射線仍依當前互動狀態顯示，不因放置結束而永久消失。

輸入路由依序處理：

1. 已取得手勢擁有權的拖曳流程，持續處理直到放開或取消。
2. 沒有拖曳時，先判定可見且未被遮擋的 UI；UI 吃掉操作後，不觸發背後的地形或道具。
3. 其餘情況才接受場景選取。

UI 與場景命中需依距離及遮擋規則比較，不能讓面板穿過前景物件接受點擊。放置查詢則維持既有專用 Surface 規則，預覽與已放置道具不遮擋地形落點查詢。

### S3 實作決策（2026-11-06）

- SimulationWorldRaycaster 明確指定 Camera、RightController/RayOrigin、忽略的角色根節點、Canvas、sceneMask 與 maxDistance。預設距離 100 m、遮罩排除 Ignore Raycast；另外排除角色階層的碰撞器，專用射線視覺沒有碰撞器。RayOrigin 位於右球前表面（本地 Z=0.5，繼承球尺寸後為 0.06 m），不改 S1 球設定。
- 攝影機射線先查詢 UI 與場景取得參考點，無命中採 100 m；再從 RayOrigin 朝參考點建立實際 Ray，重新查詢世界平面交點、Graphic 矩形、UGUI mask/filter 及場景距離。較近或同距離的場景碰撞器優先，空白背景仍阻擋。LineRenderer 寬 0.003 m、命中球直徑 0.016 m，使用專用 SimulationRay 材質；無命中延伸到有限距離並隱藏標記。
- VR 的 InputSystemUIInputModule 停用，既有 EventSystem 保留，SimulationRayInputModule 是唯一有效模組，不派送 navigation、submit 或拖曳。LateUpdate 在角色移動與面板跟隨後查詢；hover／down／up／click 使用同一實際 Ray 結果。項目 hover 藍色、press 橘色、click 綠色 0.3 秒，提示顯示 CLICK: 穩定 ID；僅記錄既有 Definition，不建立任何道具。
- S3 取代 S2 的純顯示設定：SimulationPropCatalog.Awake 只 Bind，不再覆寫 Graphic.raycastTarget。場景只讓面板背景、viewport、四個項目背景接受查詢；圖示與文字不接收。沒有 GraphicRaycaster 或桌面手勢元件。CanvasGroup 的 alpha／interactable／blocksRaycasts 由 SimulationPropMenu 管理。
- IsExpanded 仍為目標；IsInteractive 要求元件啟用、目標展開、progress 到達 1 且 Canvas 有效。收合要求當影格立即取消操作；開合途中可見背景保留遮擋，但不接收新操作。原 S2 wasPressedThisFrame、快速反向及失焦後 Tab release 防護保持。
- viewport 332×288 px，content 332×288 px；四列每列 72 px，項目高 66 px。ScrollRect 垂直、Clamped、無慣性，scrollSensitivity=24；使用者試玩後將 Wheel Units Per Step 設為 3（目前場景設定），滾輪輸入先除以 3；四項預設無溢出。滾輪只有實際命中 viewport 或其可見子項且面板可互動時派送，不送拖曳。
- 右鍵觀看期間停止瞄準與全部 UI 按鍵／滾輪派送，隱藏射線及清除命中，不接管 S1 游標。失焦、暫停、離開有效 Game View、停用、收合或卸載會送取消用 pointerUp、清除 hover／press；中斷後需觀察左鍵放開才能開始新操作。Editor 另外要求 focusedWindow 與 mouseOverWindow 均為 GameView，不能以 Inspector／Scene View 的滑鼠取得操作。

S3 測試區分 Input System 測試裝置、直接世界射線查詢、生命週期回呼與原生 Game View 操作，詳見 [S3Validation](S3Validation.md)。本階段不含拖曳擁有權、預覽、放置、指引線、選取刪除或場景選單；第 7–8 節的相關內容仍為 S4–S5 規劃。

## 7. 道具放置與選取流程

### 放置

1. Tab 開啟左手面板。
2. 右手射線指向道具，按住左鍵。
3. 超過拖曳門檻並拖出項目後，建立唯一一個對應預覽。
4. 射線指向指定 TerrainCollider，依命中位置、法線與底部錨點更新姿態。
5. 顯示有效／無效預覽、射線與落點指引；在 UI 上隱藏放置預覽，不保留可提交的舊落點。
6. 放開時重新查詢 UI 與地形；有效就建立一個正式道具，否則取消。
7. 清理預覽、指引與手勢狀態，清單來源保留供重複操作。

取消條件包含 Esc、Tab 關閉面板、失焦、離開有效視窗、控制器停用與場景卸載。中斷後回到視窗不得意外放置。放置結束的同一次放開不得額外觸發選取。

### 選取與刪除

沒有拖曳且射線不被 UI 接收時，點擊已放置道具可選取；點擊另一道具切換，點擊地形或空白清除。來源面板的新拖曳也清除選取。

模擬模式建議使用物件旁的世界空間刪除選單，朝向觀看者並可由右手射線操作；桌面模式維持現有螢幕空間選單。新選單需處理遮擋、距離與可讀性，避免直接套用目前的螢幕邊界限制。刪除後清除目標與選單參照。

## 8. 程式責任與現有系統整合

沿用 Unity、URP、Input System、UGUI 與既有道具資料，不以模擬需求為由升級套件。純鍵鼠模擬可先使用自訂輸入與射線轉接，不預設必須安裝 XR 套件；正式接設備時再選定套件與硬體。

| 責任 | 建議處理方式 |
| --- | --- |
| 角色移動與觀看 | 獨立模擬角色元件，避免放入放置控制器 |
| 控制器射線 | 輸出世界射線、命中與按下／持續／放開意圖 |
| 左手面板 | 管理錨點、開關與道具項目呈現 |
| UI 與場景輸入路由 | 統一判定命中、遮擋、手勢擁有權與事件消耗 |
| 放置流程 | 共用開始、更新、確認、取消及預覽生命週期 |
| 地形查詢 | 接受世界射線；桌面螢幕座標透過攝影機轉成射線後共用 |
| 選取與選單 | 共用選取目標與刪除規則，各模式使用適合的呈現 |
| 場景離開清理 | 取消互動、清除選取、恢復游標，讓卸載清除場景物件；返回入口於 I1 加入 |

現有 `PlacementController` 直接依賴滑鼠、螢幕座標及 `PropItemDragHandler`，不能只把 Canvas 移到左球就視為完成。需把來源手勢與取消條件移到輸入轉接層，讓放置核心接受射線與操作意圖；保留桌面操作的相容入口及回歸測試。

`SurfacePlacementQuery` 目前以螢幕座標建立射線，需增加世界 Ray 查詢入口，桌面入口轉接後沿用同一姿態計算。`PropSelectionController` 同樣直接讀取滑鼠與攝影機射線，需分離輸入與選取／刪除規則，避免 VR 控制器與既有滑鼠監聽同時處理操作。指引呈現僅在 VR 場景配置。

維持明確元件與 Inspector 參照，不導入大型框架。UI 事件系統需統一管理，避免桌面與模擬輸入同時送出事件。

場景選單在兩版完成後才實作；目前只預留停用與卸載清理能力，不提前建立選單或切換系統。最終載入與建置規格見第 12 節。

## 12. 後續場景選單與整合交付

- 兩版完成後新增 `Assets/SurfaceForge/Scenes/SceneMenu.unity`，提供「桌面版驗收」與「VR 模擬驗收」按鈕，以單場景替換載入 Main 或 VRSimulation，不採疊加載入。
- 兩個操作場景加入可點擊的「返回場景選單」入口；VR 入口使用右控制器射線可操作的 UI，沿用 UI 輸入優先規則，不占用既有 Esc 取消及面板關閉行為。
- 返回前取消拖曳、清除指引與選取、恢復游標；已放置物件隨場景卸載清除。再次進入為初始狀態，不保存或跨場景同步道具。
- Build Profile 包含 SceneMenu、Main 與 VRSimulation，以 SceneMenu 為啟動場景，Windows x64 統一輸出至 `Builds/Windows/`；不以兩個獨立執行檔作為最終交付。
- I2 驗證啟動選擇、兩方向返回與重新進入，反覆往返至少 10 次；確認只有一套有效攝影機、AudioListener 與 EventSystem，無殘留預覽、UI、重複輸入及意外放置。
- 完整桌面驗收、VR 驗收、視窗縮放與失焦測試皆需在 Editor 外執行，記錄提交、平台、結果與限制。錄影呈現場景選單及兩版主要流程；模擬驗收不等於實機 XR 驗收。


## S4 實作補充（2026-11-06）

本節更新 S3 邊界及第 7–8 節放置部分的目前狀態；S3 段落保留其當時範圍，選取與刪除仍屬 S5。SurfacePlacementQuery 的螢幕入口轉接世界 Ray；PlacementController 共用底部姿態、有效性、唯一預覽、PlacedProp 建立與取消，VR 路由不啟用桌面滑鼠監聽。

按住來源後，以右球射線與來源平面交點移動至少 18 UI 單位，且離開來源矩形取得放置擁有權。取得前普通點擊維持 S3；按住期間不捲動，取得後不派送其他項目的新操作，持續至放開或取消。UI 保持阻擋；放開重查當前 UI 與指定 TerrainCollider。UI 上隱藏預覽，無地形時改為射線前方 5 m 的紅色無效預覽。

操作射線保持既有直線。放置另用專用 alpha=0.35 預覽材質、0.018 m 金色線與半徑 0.95 m 的法線圓環；線連接預覽頂部上方與真正底部落點。只有非 UI 且合法地形命中時顯示指引，結束與中斷清理，不修改共享材質。

拖曳期間阻止新進入右鍵觀看，結束仍按右鍵須先放開。Esc 優先取消拖曳，無拖曳才收合；Tab 收合先取消。保留 S2 同影格短按與動畫防護、S3 世界遮擋及滾輪 3／24。來源、路由、角色、射線、核心與面板停用及既有焦點／暫停／有效 Game View／卸載條件取消，左鍵需先放開。測試方法、結果及尚待使用者精準度與舒適度確認見 [S4Validation](S4Validation.md)，不推定為原生焦點、連續縮放、Windows 或 XR 驗收。
